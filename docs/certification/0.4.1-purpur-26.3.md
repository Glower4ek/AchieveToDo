pair starts, joins and enforces in every preset, with the new and changed cases of 0.4.0:

reran it unchanged. Full test suites: Fabric 942 tests, 0 failures; Purpur green.

The advancements screen itself is client presentation and is not opened by the harness: the owner opened it in a
single-player world with the fixed mod and confirmed that it works, and also checked the landmark border and the BACAP
file dialog.
