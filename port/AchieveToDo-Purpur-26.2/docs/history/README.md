# Port development notes (history)

Design and stage notes written while the Purpur port was built (stages S3A to S4L, the restriction engine, the
inventory UI and its resource pack). They describe the 0.2.x development and are kept for reference only.

They are superseded: the legacy restriction path, the inventory UI and the resource pack were removed in 0.3.0, and
the current status is the runtime certification in [docs/certification](../../../../docs/certification/). For
running a server see [STARTING_THE_SERVER.md](../../STARTING_THE_SERVER.md).
